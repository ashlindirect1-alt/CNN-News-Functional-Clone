# CNN News Functional Clone

A functional web-based news portal developed for CWI Task 34.

## 🚀 Features

- Featured news
- Breaking news section
- World news
- Politics
- Business
- Technology
- Sports
- Entertainment
- Search functionality
- Article details
- Related news categories
- Comment section
- LocalStorage
- Responsive design
- Dynamic news loaded through Express API
- JSON-based news data
- Node.js and Express.js backend

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- JSON
- LocalStorage
